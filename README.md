# Изменение суточного профиля электропотребления домохозяйства

Исследование суточного профиля активной электрической мощности на основе поминутных измерений одного домохозяйства.

**Тема исследования:** «Изменение суточного профиля электропотребления домохозяйства: влияние полноты исходных данных и методов их обработки на результаты анализа».

## 1. Цель исследования

Цель работы — исследовать различия суточных профилей активной электрической мощности в выбранные периоды и оценить влияние пропусков измерений и способов обработки временного ряда на результаты анализа.

Исследование проводится по двум основным направлениям:

1. Сравнение суточных профилей электропотребления в разные сезоны.
2. Изучение влияния отсутствующих измерений и методов обработки на характеристики суточного профиля.

Основная анализируемая величина — средняя за минуту активная электрическая мощность, кВт.

## 2. Исходные данные

Используется открытый набор данных [Individual Household Electric Power Consumption](https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption) из UCI Machine Learning Repository.

Авторы: Georges Hebrail, Alice Berard.

DOI: https://doi.org/10.24432/C58K54

Набор содержит поминутные измерения электрических величин одного домохозяйства за период с декабря 2006 года по ноябрь 2010 года.

Основные характеристики используемого файла:

| Характеристика | Значение |
|---|---|
| Файл в репозитории | [household_power_consumption.zip](data/raw/household_power_consumption.zip) |
| Количество записей | 2 075 259 |
| Количество исходных столбцов | 9 |
| Начало наблюдений | 16.12.2006, 17:24 |
| Конец наблюдений | 26.11.2010, 21:02 |
| Интервал регистрации | 1 минута |
| Разделитель | `;` |
| Размер архива ZIP | 20 640 916 байт |
| Размер исходного TXT после распаковки | 132 960 755 байт |

Переменная `Global_active_power` содержит среднюю за минуту активную мощность домохозяйства в кВт.

Дополнительно представлены реактивная мощность, напряжение, сила тока и показания трёх дополнительных счётчиков электрической энергии.

В 25 979 записях отсутствуют значения электрических величин. Временные метки при этом образуют непрерывную поминутную последовательность.

Исходный файл не изменяется; преобразования выполняются в памяти и сохраняются в отдельных результирующих таблицах.

## 4. Программные средства

Обработка выполняется на языке Python в Jupyter Notebook, Google Colab или
из командной строки. Исходные измерения считываются из каталога `data/raw`.

Общие операции загрузки, проверки и обработки данных реализованы в
`ipd_analysis.py`. Каждый ноутбук считывает выбранный источник один раз
в начале выполнения. Сценарий `run_analysis.py` предназначен для
последовательной обработки всех поддерживаемых исходных файлов.

Используемые библиотеки:

- **pandas** — работа с таблицами и временными рядами;
- **NumPy** — численные вычисления;
- **Matplotlib** — построение научных графиков.

Список зависимостей приведён в `requirements.txt`.

Работоспособность проверена на Python 3.12, pandas 2.2.3, NumPy 2.3.5
и Matplotlib 3.10.8. Файл `metadata.json` в каталоге результатов фиксирует
версии программ, параметры обработки и контрольные суммы исходного файла и кода.

Для дополнительной визуализации используется LabPlot 2.12.

[График влияния искусственных пропусков](<графики/05_влияние_пропусков.png>)
содержит суточные профили и разности между профилями с пропусками и
профилем без искусственных пропусков. На панели разностей дополнительно
показано 15-минутное скользящее среднее для выделения общей тенденции.
Погрешности рассчитываются по исходным, несглаженным значениям.

В эксперименте за сентябрь 2008 года искусственно исключены измерения
за **15–17 сентября** (три полных суток, 10 % наблюдений за месяц).
Для оценки зависимости результата от расположения пропусков дополнительно
рассмотрены 100 случайных выборок и все 28 возможных положений трёхдневного
непрерывного пропуска с началом в 00:00. Эмпирические квантили 2,5 % и
97,5 % характеризуют разброс погрешностей между рассмотренными сценариями.

[График разброса ошибок](<графики/05_устойчивость_к_пропускам.png>) и
[таблица отдельных сценариев](<статистические результаты/05_устойчивость_сценарии.csv>)
позволяют проверить влияние расположения пропусков. Средние значения,
стандартные отклонения и квантили ошибок приведены в
[сводной таблице](<статистические результаты/05_устойчивость_сводка.csv>).

Для непрерывного пропуска 15–17 сентября MAE суточного профиля составляет
**0,029354 кВт**. Средняя MAE по 28 положениям блока равна **0,035163 кВт**,
а по 100 случайным выборкам — **0,033839 кВт**. Следовательно, оценка
влияния типа пропусков зависит от выбранных временных интервалов;
единичный эксперимент не характеризует весь диапазон результатов.

Здесь MAE (*mean absolute error*, средняя абсолютная ошибка) — среднее
значение модулей разностей между исходным и изменённым суточными профилями
для 1440 минут суток. Единица измерения MAE — кВт.

## 6. Основные результаты

Среднемесячная активная мощность, рассчитанная по имеющимся измерениям:

| Месяц | Средняя мощность, кВт | Полнота данных, % |
|---|---:|---:|
| Январь 2008 | 1,460 | 99,998 |
| Апрель 2008 | 1,116 | 100,000 |
| Июль 2008 | 0,795 | 99,996 |
| Сентябрь 2008 | 0,988 | 100,000 |
| Август 2009 | 0,665 | 98,004 |
| Август 2010 | 0,591 | 83,813 |

В выбранных месяцах 2008 года наблюдаются различия среднего уровня активной мощности и формы суточных профилей.

Максимумы средних почасовых профилей выбранных месяцев приходятся на 20:00–21:59.

Среднее арифметическое и медиана дают различающиеся оценки уровня мощности в отдельные интервалы суток.

При увеличении окна скользящего среднего локальные максимумы становятся менее выраженными.

Погрешности суточных профилей, рассчитанных по неполным данным, зависят не только от доли исключённых измерений, но и от их расположения во времени.

Полученные результаты относятся к исследуемому домохозяйству; установить причины наблюдаемых сезонных различий по этим данным нельзя.

## 7. Воспроизведение результатов

Для воспроизведения расчётов требуется Python с библиотеками,
перечисленными в `requirements.txt`, и исходный архив в `data/raw`.

Последовательность команд из терминала:

```bash
git clone https://github.com/sonyxoxo/ipd.git
cd ipd
python -m pip install -r requirements.txt
python run_analysis.py --all
```

Результаты каждого исходного файла сохраняются отдельно в
`результаты/<имя-источника>-<код>/`. В каталоге находятся таблицы CSV,
графики PNG и `metadata.json` со сведениями о запуске. Для пошагового
изучения вычислений предусмотрены пять ноутбуков из `ноутбуки python`.

В Google Colab ноутбуки клонируют репозиторий в `/content/ipd` при его
отсутствии. После обновления репозитория уже существующий клон можно
синхронизировать командой `git -C /content/ipd pull --ff-only`.
Состояние временной файловой системы Colab между сеансами не сохраняется.

При нескольких источниках отдельный ноутбук открывает явно выбранный файл,
например `choose_source("data/raw/имя.csv")`. Параметр `--all` обрабатывает
все поддерживаемые файлы из `data/raw`.

Для проверки кода предусмотрены тесты в `tests/` и конфигурация GitHub Actions
в [`.github/workflows/tests.yml`](.github/workflows/tests.yml). Результаты
проверок опубликованных коммитов доступны во вкладке **Actions** репозитория
при включённом выполнении рабочих процессов.

### Новые измерители: названия столбцов и единицы

Для файла `data/raw/meter_example.csv` с заголовками `datetime;power_w`
сопоставление имён и единиц задаётся в `analysis_config.json`:

```json
{
  "datasets": {
    "meter_example.csv": {
      "columns": {"timestamp": "datetime", "Global_active_power": "power_w"},
      "units": {"Global_active_power": "W"},
      "sampling_minutes": 1,
      "delimiter": ";"
    }
  }
}
```

Мощность переводится из ватт в киловатты до статистической обработки.
Формат даты при необходимости задаётся параметром `date_format` в синтаксисе
Python `strptime`. Для каждого нестандартного набора данных используется
отдельная запись в `datasets`.

Реализованные алгоритмы рассчитаны на **поминутные измерения**.
Для данных с шагом 5 или 15 минут потребуются соответствующие изменения
временной сетки и расчёта энергии. При неподдерживаемом шаге или неизвестной
единице измерения программа выдаёт диагностическое сообщение.

Названия столбцов результирующих CSV используются в латинской записи;
назначение величин и единицы измерения указаны в ноутбуках. Запуск анализа
и проверок описан в разделе «Воспроизведение результатов» выше.

Контрольные характеристики исходного набора UCI:

- 2 075 259 записей;
- 9 исходных столбцов;
- 25 979 записей с отсутствующей активной мощностью;
- непрерывная последовательность поминутных временных меток.

## 8. Ограничения исследования

Исследование основано на наблюдениях одного домохозяйства.

Сравнение отдельных месяцев не позволяет распространить полученные закономерности на другие годы и домохозяйства без дополнительной проверки.

Результаты экспериментов с искусственными пропусками зависят от выбранного месяца и способа формирования пропусков.

Сглаживание изменяет локальную структуру суточного профиля; его применение учитывается при интерпретации графиков.

В работе не исследуются причинные механизмы изменения электропотребления.
